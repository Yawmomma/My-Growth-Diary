# My Growth Booklet

A personal growth tracking app built as a single HTML file.

## Features
- Save and collect compliments received
- Record personal discoveries, patterns, triggers and wins
- Complete weekly reflection check-ins
- All data stored privately on your device
- Works offline once downloaded

## Privacy
All data entered into this app is stored locally on your device only.
Nothing is sent to any server or third party.
The app itself contains no personal information.

## Usage
Open index.html in any modern browser.
On mobile, open in Chrome or Safari and use
"Add to Home Screen" for easy access.

## Tech
Single file HTML app using IndexedDB for local storage.
No frameworks, no dependencies, no internet required.
